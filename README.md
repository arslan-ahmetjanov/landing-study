# Учебный лендинг «Уфанет»

Макет посадочной страницы интернет-провайдера для практической работы № 2 по дисциплине «Цифровой маркетинг»: УГНТУ, группа БИЦз-22-01, направление 09.03.03 «Прикладная информатика». Показывает структуру, тексты и вёрстку страницы; это не официальный сайт АО «Уфанет», формы ничего не отправляют.

Демо: **https://arslan-ahmetjanov.github.io/landing-study/**

## Что внутри

- Один `index.html`: разметка, стили и скрипт формы, без сборки и внешних библиотек.
- Десять блоков от шапки до подвала: первый экран с формой, преимущества, тарифы, шаги подключения, отзывы, вопросы и ответы, финальная форма.
- Адаптивность на двух медиазапросах, 960 и 700 px.
- Страница закрыта от индексации метатегом `<meta name="robots" content="noindex, follow">`. Файла `robots.txt` в репозитории нет: на GitHub Pages он читается только из корня домена (`…github.io/robots.txt`), а не из подпути проекта.

## Как посмотреть

Локально — открыть `index.html` двойным кликом, сервер не нужен. Онлайн — ссылка на GitHub Pages в начале README.

## Известные ограничения

- Заявки не отправляются и не сохраняются: форма перехватывается скриптом, формы идут `method="post"`, поэтому при отключённом JS телефон не попадает в query-строку.
- Телефоны оператора в макете заменены на условные (`8 800 000-00-00`), чтобы по ним не звонили.
- Цены и оценки взяты из открытых источников на 20.11.2026 и могут устареть.
- Один файл без сборки и тестов: проверка ручная, в браузере.
