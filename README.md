# Учебный лендинг «Уфанет»

Посадочная страница для практической работы № 2 по дисциплине «Цифровой маркетинг» (УГНТУ, группа БИЦз-22-01).

**Это не официальный сайт компании.** Макет собран для задания: он показывает структуру, тексты и вёрстку посадочной страницы интернет-провайдера. Никаких заявок страница не принимает — форма выводит сообщение на экране и никуда данные не отправляет.

## Что внутри

Один файл `index.html`: разметка, стили и небольшой скрипт обработки формы. Внешних библиотек и шрифтов нет, поэтому страница открывается и локально, и с GitHub Pages без сборки.

Блоки: шапка, первый экран с формой, цифры-доказательства, преимущества, тарифы, шаги подключения, отзывы, вопросы и ответы, финальная форма, подвал. Адаптивность — от 320 до 1440 пикселей.

## Данные

Тарифы, скорость, отзывы и услуги взяты из открытых источников на 20.11.2026:

- тарифы и покрытие — агрегатор 101internet.ru;
- скорость в Уфе — TelecomDaily, измерения август–сентябрь 2025 года;
- оценки и темы отзывов — Яндекс.Карты, 2ГИС;
- услуги и телефоны — открытые страницы компании.

Цены на сайте оператора могут отличаться: они зависят от акции и адреса.

## Технические детали

- вёрстка без фреймворков, один файл;
- шрифт — системный стек, без загрузки извне;
- форма собрана на HTML и JS, без бэкенда;
- в `<head>` стоит `noindex`, чтобы учебный макет не попадал в поиск.

## Как посмотреть локально

Скачать `index.html` и открыть двойным кликом в браузере.
